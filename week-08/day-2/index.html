What am I learning?

Three lines today, and they are the three lines behind nearly every button on the internet.

The first finds the button. Every element can have an id, and document.querySelector("#action") means “find the thing whose id is action.” The # is what says id — leave it off and JavaScript finds nothing.

The second listens. addEventListener("click", function () { … }) means “when this is clicked, run the code inside the curly brackets.” Here is the part that surprises people: that code does not run when the page loads. It sits there waiting. It only runs when the click actually happens.

The third changes what you see. textContent is the words inside an element, and setting it swaps them for new ones. That is the moment your page responds to a person.
